# SQL-Projects
Collection of SQL projects covering querying, joins, aggregate functions, subqueries, CTEs, and data cleaning, applied to real-world style datasets to solve practical data problems. Tools used: MySQL
What's in here:
Data Querying – Writing SELECT queries with filtering, sorting, and grouping to pull meaningful information out of raw tables.
Joins – Combining data across multiple tables using INNER, LEFT, RIGHT, and FULL joins to answer questions that a single table can't.
Aggregate Functions – Using COUNT, SUM, AVG, MIN, MAX along with GROUP BY and HAVING to summarize and analyze data.
Subqueries & CTEs – Breaking down complex problems into simpler, readable steps using nested queries and Common Table Expressions.
Data Cleaning – Handling duplicates, NULLs, and inconsistent data using SQL itself before analysis.
Case Studies – Applying all of the above to solve specific business-style problems (sales analysis, customer segmentation, admissions data, etc. ).
Why I made this:
This repo is where I document my SQL learning and practice, moving beyond just syntax to actually thinking in terms of how a database question needs to be broken down and solved. Each project reflects a different type of problem I worked through.
Tools used: MySQL
